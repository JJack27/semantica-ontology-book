# 本体之路 · Semantica × 本体专家之路

一本为「双目标」锻造的中文交互书：**成为 [semantica](https://github.com/semantica-agi/semantica)
repo 的专家，同时成为本体（Ontology）领域的专家**。由 personal-book-forger 技能生成，
内容对照 semantica main 分支（2026-08-25）真实源码写就。

## 打开方式

直接用浏览器打开 `zh/index.html`。**无需服务器、无需构建、无需联网**
（知识图谱的 Cytoscape.js 走 CDN，离线时自动回退内置布局）。
每章是自包含的单文件 HTML，`file://` 下一切功能可用。

支持**亮 / 暗双主题**：顶栏的 ☀/☾ 按钮切换，偏好持久化（`pbf:theme`），
首次访问跟随系统外观；全部图解使用 CSS 变量，两主题下均可读。

## 结构（13 章 · 四部分）

| 部分 | 章 | 内容 |
|---|---|---|
| 一 · 本体领域基础 | 1–4 | 三元组/IRI/同一性 → RDFS/OWL → SHACL/SKOS → 工程方法论 |
| 二 · repo 全景 | 5–7 | 架构与核心抽象 → 端到端数据流 → 智能层四件套 |
| 三 · ontology 深潜 | 8–12 | 六阶段生成 → 类/属性推断 → SHACL 生成验证 → 治理生态 → 平台集成 |
| 四 · 上手实操 | 13 | 环境、测试地图、贡献流程、PR 候选 |

每章含：学习目标、内联 SVG 图解、可交互演示（共 10 个）、章末测试（8–10 题，
≥80% 视为「学够了」，软门槛）。进度按书名+语言存于浏览器 localStorage。

## 本书的诚实性特色

全书标注了四处「文档说与代码做不一致」（占位验证器、装饰性参数、5/6 阶段口径、
Rete 匹配器局限），并附一个真实的注入漏洞修复案例（commit 220fb10e）——
第 13 章把它们全部转化为可执行的 PR 候选。
